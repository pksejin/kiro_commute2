# 🚀 직원 출퇴근 관리 시스템

GPS 기반 출퇴근 인증 시스템 (PWA)

## ✨ 주요 기능

- 📍 GPS 기반 위치 인증 (80m 반경)
- 📱 PWA (Progressive Web App)
- ☁️ Google Drive 동기화
- 🏢 협력사 관리
- 👥 사용자 관리
- 📊 출퇴근 리포트

## 🚀 시작하기

[앱 실행하기](https://pksejin.github.io/kiro_commute2)

## 📱 모바일 설치

1. 위 링크로 모바일 브라우저에서 접속
2. "홈 화면에 추가" 또는 "설치" 버튼 클릭
3. 위치 권한 허용
4. 앱처럼 사용!
